# Kendall Doerr | A Career Collection

A one-page portfolio for knowledge management, content governance, and AI-ready content work. It is styled as a streaming-service title page, with each project as an "episode."

**View it:** https://kdoerr731.github.io/portfolio/

## What's on the page

- **Highlights:** four short reasons to work together
- **Episodes:** six projects, each with a popup covering the challenge, approach, impact, and why it matters
- **Reviews:** short quotes from colleagues' LinkedIn recommendations, shown by initials
- **More details:** focus areas, working style, and tools

## About this repo

- `index.html` is the whole site. It is a single self-contained file with no external libraries, scripts, or images to load.
- The hero photograph is embedded in the file.
